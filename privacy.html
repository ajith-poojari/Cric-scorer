Data & Security Transparency

Privacy Policy

Effective & Last Updated: November 2026

Scoreboard is a real-time community and tournament cricket scoring platform designed to work with minimal personal data. There are no mandatory user accounts, no marketing sign-up forms, and no personal profiling required to score or watch a match.

1. Information Stored During a Match

  • Match Setup & Roster Data: Team names, player names, batting/bowling styles, venue, pitch condition, and toss details entered by the scorer to operate the live scoreboard.
  • Ball-by-Ball Telemetry: Delivery records, runs, extras, wickets, partnerships, and match pause status needed to compute live scorecards and run progression graphs.
  • Anonymous Session Identifier: When connected to cloud sync, Firebase Authentication assigns a random anonymous session UID to authorize real-time updates from the active scorer's browser without collecting your name, email, or phone number.
  • Cryptographic Scorer Hash: A one-way SHA-256 hash of the match scorer password is stored solely to let the original scorer resume control of a match. Your plaintext password is never stored or transmitted.

2. What Is Never Collected

  • No third-party advertising cookies, behavioral trackers, or cross-site pixels.
  • No personal contact lists, GPS location tracking, or payment details.
  • No resale or external sharing of club, school, or tournament rosters.

3. Cloud Sync & Local Storage

Live match data is synchronized via Google Firebase Realtime Database so viewers with your 5-character match code can watch every delivery in real time. Saved team rosters and offline backup states are also cached locally in your browser's localStorage so you never lose progress if mobile reception drops mid-over.

4. Data Retention & Self-Hosting

Match records remain accessible via their match code until cleared by the database administrator. Because Scoreboard is deployable via GitHub Pages with your own Firebase repository secrets, organizations and leagues can host isolated instances under their own cloud project.

5. Contact & Support

For privacy inquiries, data removal requests, or tournament deployment support, please open an issue on the project's GitHub repository or contact the administrator via the in-app Match Menu → Help & Info panel.
